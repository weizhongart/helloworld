# 即时记账 App

一个现代化的个人记账应用，使用纯前端技术开发，支持本地数据存储。

## 功能特性

### 📊 核心功能
- **添加交易记录** - 支持收入和支出两种类型
- **分类管理** - 预设常用分类，包含emoji图标
- **实时统计** - 自动计算总余额、收入和支出
- **数据可视化** - 支出分类饼图和详细统计

### 🎨 界面设计
- **现代化UI** - 采用毛玻璃效果和渐变色设计
- **响应式布局** - 完美适配手机、平板和桌面设备
- **流畅动画** - 丰富的交互动画和过渡效果
- **直观操作** - 简洁易用的用户界面

### 🔧 实用功能
- **搜索筛选** - 支持按描述、分类、类型筛选
- **编辑删除** - 可修改和删除历史记录
- **本地存储** - 数据保存在浏览器本地，无需联网
- **快捷操作** - 支持键盘快捷键和触摸手势

### 📱 移动优化
- **触摸友好** - 针对移动设备优化的交互设计
- **滑动删除** - 移动端支持滑动删除记录
- **离线使用** - 无需网络连接即可使用

## 使用方法

### 1. 添加记录
1. 填写消费描述
2. 输入金额
3. 选择分类
4. 选择收入或支出类型
5. 选择日期（默认今天）
6. 点击"添加记录"

### 2. 查看统计
- **余额卡片** - 顶部显示总余额、收入、支出汇总
- **支出统计** - 底部饼图显示各分类支出占比
- **详细列表** - 右侧列表显示各分类的具体金额和百分比

### 3. 管理记录
- **编辑** - 点击记录上的"编辑"按钮修改信息
- **删除** - 点击"删除"按钮移除记录
- **批量清空** - 点击"清空记录"按钮删除所有数据

### 4. 搜索筛选
- **文本搜索** - 在搜索框输入关键词搜索描述或分类
- **分类筛选** - 选择特定分类查看相关记录
- **类型筛选** - 选择收入或支出查看对应记录

### 5. 快捷操作
- **Ctrl + Enter** - 快速提交表单
- **Esc** - 关闭编辑弹窗
- **左滑删除** - 移动端左滑记录项可快速删除

## 技术架构

### 前端技术
- **HTML5** - 语义化标签和现代化结构
- **CSS3** - Flexbox/Grid布局、动画效果
- **JavaScript ES6+** - 原生JS，无外部依赖
- **Canvas API** - 自绘制饼图

### 数据存储
- **localStorage** - 浏览器本地存储
- **JSON格式** - 结构化数据保存
- **实时同步** - 操作即时保存

### 响应式设计
- **移动优先** - Mobile First设计策略
- **断点适配** - 768px、480px断点优化
- **弹性布局** - 自适应不同屏幕尺寸

## 安装使用

1. 下载项目文件
2. 直接在浏览器中打开 `index.html`
3. 无需任何安装或配置

## 数据安全

- 所有数据保存在用户本地浏览器中
- 不会上传任何个人信息到服务器
- 清除浏览器数据会同时清除记账数据
- 建议定期备份重要数据
